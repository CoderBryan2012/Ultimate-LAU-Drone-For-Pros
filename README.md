# Ultimate-LAU-Drone-For-Pros
This project is from a ROBLOX game called "**Plant with Coding**" by Lated Graham where you code a drone that allows you to plant and do all sorts of things.

Game Link: https://www.roblox.com/games/122761763017872/Plant-with-Coding

Script Version: 5.5.0

# FEATURES
**5 Buttons:** Plot, AFK Plot, Teleport To Drone, Sell All Crops, Print All Stocks

**2 Chatevents:** buy, buy-max, leaderboard-check-rank

**Buttons:**

**Plot:** Harvests all crops and stops when finished.

**AFK Plot:** Harvests all crops and auto sells crops infinitely. 

**Teleport To Drone:** Teleports the player to the drone.

**Sell All Crops:** Sells all crops in the players inventory.

**Print All Stocks:** Prints all the stocks in the output and displays the time remaining before the stock resets. 

**Chat Events:**

**Buy:** Buys a plant seed of your choice. ex. player says "buy wheat"

**Buy-max:** Buys the maximum amount of plant seed of your choice. ex. player says "buy-max wheat"

**Leaderboard-check-rank:** Displays your rank on the leaderboard, displays null if not in the top 50.

# REQUIREMENTS
**Unlocked Code:** Market, String, PlayerV2, DroneV2

Space for 3 Scripts; 2 Module Scripts, 1 Normal Script.

(optional) Upgrading your Drone in the Software shop is necessary for a faster drone.
